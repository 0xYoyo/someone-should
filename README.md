# someone should.

every "someone should make an app that…" on the internet — built.

Live: https://0xyoyo.github.io/someone-should/ · Each tool: `/tools/<slug>/`

How: wishes harvested from Hacker News, Software Recommendations SE and Reddit; ranked by agreement; the top 100 built as single-file, zero-network tools by Opus 5.5 subagents under a verify gate (`scripts/verify.mjs`); approved by Yoav Zrihan. Wish for one: open an issue titled `someone should make an app that …`.

Sources are quoted one line each with a link; no usernames are stored or shown.
